# Backend Scoring Persistence Plan

1. Add score fields to the article persistence model and SQLite schema with safe additive migration.
2. Move score calculation into reusable service helpers that can score both stored articles and incoming feed seeds.
3. Persist scores during feed ingestion and recompute scores when article full content changes.
4. Keep list/detail responses backward compatible while preferring persisted scores and falling back for old rows.
5. Add tests for persisted score population and refresh-triggered rescoring, then run `go test ./...`.
