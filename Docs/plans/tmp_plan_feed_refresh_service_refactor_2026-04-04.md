# Feed Refresh Service Refactor Plan

- 目标: 将 feed 刷新、脚本执行、icon 发现/下载与批量刷新编排从 `backend/internal/handler/server.go` 下沉到 `backend/internal/service/`，让 handler 仅保留 HTTP 适配职责。
- 约束: 不改变现有 HTTP 接口与返回语义；继续保留单次 feed 刷新总超时、脚本 stdout 上限、summary backfill 与 icon 复用行为。
- TDD:

  - 验证测试在 `FeedRefreshService` 缺失前失败。
  - 再实现最小 service 并改 `Server`/scheduler 接线。
- 代码边界:
