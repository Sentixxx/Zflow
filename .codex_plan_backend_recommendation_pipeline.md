# Backend Recommendation Pipeline Plan

1. Extend the article domain model with recommendation score fields without changing existing required fields.
2. Add a service-level scoring and sorting pipeline so repository remains a raw persistence layer.
3. Expose optional `sort` query handling on `GET /api/v1/articles` and keep the default latest-first behavior for compatibility.
4. Return recommendation scores on article list/detail responses so the front-end can consume backend scores transparently.
5. Add service and handler tests for sorting behavior and run `go test ./...`.
