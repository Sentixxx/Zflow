# Lessons

- 2026-03-22: 规划推荐相关能力时，先定义稳定数据结构和降级路径，禁止把 UI 展示字段直接拿去承载推荐、记忆和解释三种语义。
- 2026-03-22: 网络代理默认值不能劫持 `localhost/127.0.0.1` 的抓取链路，否则本地测试和自托管本地源会被错误代理，导致空 feed 入库。
- 2026-03-22: 前端仓库只有 `package-lock.json` 时，必须显式声明 `packageManager` 为 `npm`，否则部分 Node/Corepack 环境会误拉取其他包管理器并触发签名校验错误。
- 2026-03-22: 用户可见摘要和正文区要分层展示；摘要适合固定在详情头部附近的独立卡片，而不是和正文模式共用同一块流式内容区。
- 2026-03-22: 已有 OpenAI 兼容 AI 设置时，新增模型能力优先复用现有 `base_url + model + api_key`，不要再单独引一套供应商专用配置。
- 2026-03-22: 正文抓取和 feed 抓取的超时预算不能共用；正文页面响应体更慢，必须拆成独立的 Readability client。
- 2026-03-22: 详情区容器不要再叠加固定 `max-width + auto margin`，否则三栏布局一旦放宽右栏就会制造肉眼可见的空白带。
- 2026-03-22: 用户不需要在摘要和正文之间切模式；更自然的路径是“摘要固定在上，正文抓到后自动接在下面”。
- 2026-03-22: 详情页自动触发正文抓取时，异步返回不能无条件 `setSelectedArticle(updated)`，否则用户切到另一篇后会被旧请求强行跳回去。
