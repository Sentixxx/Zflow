# Article List Sort Style Plan

1. Simplify the article list sort control into a single compact toolbar pill instead of a form-like label/select pair.
2. Update the toolbar markup just enough to support a cleaner caption, native select, and chevron affordance.
3. Refine the related CSS so the sort control matches the unread toggle's visual weight and spacing on desktop and mobile.
4. Run a frontend build to verify the UI change does not break compilation.
